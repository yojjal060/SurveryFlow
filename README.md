# Survey Builder

Minimal React + Express monorepo boilerplate.

## Workspaces

- `apps/web` — React 19, Vite, and TypeScript SPA
- `apps/api` — Express 5 API
- `packages/shared` — shared TypeScript types and Zod schemas

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Create local environment files from `.env.example` files. Do not commit secrets.
